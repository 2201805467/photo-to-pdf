# ورقة — تحويل الصور إلى PDF

موقع عربي يعمل داخل المتصفح، دون إرسال الصور إلى خادم.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. مكتبة PDF موجودة محليًا في `vendor`، ولا يتطلب الموقع اتصالًا بالإنترنت.

للتشغيل عبر خادم محلي عند توفر Node.js:

```sh
node server.cjs
```

ثم افتح http://127.0.0.1:3000 . لإيقاف الخادم استخدم Ctrl+C.

## المميزات

- اختيار عدة صور أو سحبها وإفلاتها، ومعاينتها وترتيبها وتدويرها وحذفها.
- صفحة لكل صورة، مع A4 أو Letter أو مقاس الصورة الأصلي (بحساب 96 بكسل/بوصة).
- ضبط اتجاه الصفحات والهوامش وجودة JPEG واسم الملف.
- معالجة الصور الشفافة بخلفية بيضاء، والحفاظ على نسب أبعاد الصور.
- دعم JPG وPNG وWebP، بحد 30 صورة و20 MB و40 مليون بكسل للصورة.
- تصغير الصور عند الحاجة إلى حد أقصى 3200 بكسل لأطول ضلع لتقليل استهلاك الذاكرة.

لا يوجد OCR؛ الصور تظل صورًا داخل PDF. الصيغ الأخرى مثل HEIC وTIFF غير مدعومة في هذه النسخة.

## التطوير

`npm.cmd install --ignore-scripts` لتثبيت اعتماد jsPDF. نسخة التشغيل المحلية من المكتبة محفوظة داخل `vendor` مع ترخيصها.

`npm.cmd test` لفحص حساب أبعاد الصفحات، الهوامش، أسماء الملفات وإنشاء PDF متعدد الصفحات.
